# Guide de Déploiement — Streamlit Cloud

## Prérequis
- Compte GitHub
- Compte Streamlit Cloud (gratuit) : https://streamlit.io/cloud

## Étapes

1. Push le code sur GitHub
2. Va sur https://share.streamlit.io
3. Clique "New app"
4. Sélectionne le repo : `ProjetIntegre-ChurnAnalysis`
5. Branch : `main`
6. Main file : `05_web_app/app.py`
7. Clique "Deploy"

L'URL sera disponible après déploiement.
